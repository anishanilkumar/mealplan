# Mealplan

A week of meals planned ahead: breakfast, lunch and dinner from the
[Recipie](https://github.com/anishanilkumar/recipie) recipe book, checked
against the pantry (Grocy), with the missing ingredients put on the shopping
list and stock booked out when a meal is cooked. Claude can suggest and fill
the week through an MCP connector.

Not built yet: see [docs/DESIGN.md](docs/DESIGN.md).
